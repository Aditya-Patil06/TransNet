\# TransNet



TransNet is a Java-based Transport Network Management System designed to manage and organize transport-related operations through a desktop application.



\## Features



\- User login system

\- Country, State, District, Taluka and Village management

\- Depot management

\- Client management

\- Employee management

\- Goods and industry management

\- Vehicle and vehicle-type management

\- Booking management

\- Booking details and reports

\- Vehicle records and reports

\- General booking reports

\- Bill and docket generation

\- PDF report generation

\- Word document generation

\- Email functionality

\- Interactive Swing-based graphical user interface

\- Animated panels and menu navigation

\- Text-to-speech and audio features

\- Calendar integration

\- MySQL database integration



\## Technologies Used



\- Java

\- Java Swing

\- MySQL

\- JDBC

\- Apache POI

\- iTextPDF

\- SwingX

\- JavaMail

\- FreeTTS

\- Maven
